プライバシーポリシー

対象：YouTube自動投稿（恋愛解剖学）（以下「本アプリ」）。最終更新日：2026年11月17日

1. 取得する情報と使い方

本アプリは、運営者本人が許可した Google アカウントについて、YouTube API の権限を使い、次のことだけを行います。

  • 運営者のチャンネルへの動画のアップロード、タイトル・説明文・サムネイル・公開日時の設定
  • 投稿先を確かめるための、チャンネル名とチャンネルIDの読み取り

Google Drive の権限は、運営者が用意した投稿待ちフォルダの動画と設定ファイルを読むためだけに使います。

2. 保存と管理

認証のトークンは、運営者の Google アカウント内の Google Apps Script にのみ保存され、外部のサーバーには送りません。投稿の記録は運営者の Google スプレッドシートに残します。

3. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。広告にも使いません。

4. Google API の利用について

本アプリによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。また、YouTube 利用規約と Google プライバシーポリシーが適用されます。

5. 許可の取り消し

本アプリへの許可は、Google アカウントの「サードパーティのアクセス」からいつでも取り消せます。
